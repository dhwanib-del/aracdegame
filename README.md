# ARCADE.exe

Playable retro-carnival browser game: Hoop Dreams basketball and Roll With It skee-ball. Includes manual controls, optional MediaPipe webcam hand tracking, scoring, results, and local personal bests.

## Deployment

Go to repository Settings → Pages and choose GitHub Actions as the source. The workflow in `.github/workflows/deploy.yml` will publish the `main` branch.

## Controls

Aim with the mouse and click/Space to shoot. Arrow keys adjust aim/power, P/Esc to pause. Camera mode: pinch to grab, open to release.

This is a playable canvas prototype, not the complete 3D Rapier engine.
